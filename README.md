# 🍽️ Food Restaurant System

This is a simple Java project that allows users to search and order food items from a menu.

## 🔧 Features
- 🔍 Search food by name  
- 🛒 Order multiple items  
- 💰 Calculate total bill  

## 🛠️ Technologies Used
- Java  
- ArrayList  
- Scanner  

## ▶️ How to Run
1. Compile the program:
   javac FoodApp.java

2. Run the program:
   java FoodApp
